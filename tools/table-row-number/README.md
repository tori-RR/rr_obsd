# Table Row Number

Obsidian 插件：自动为表格行添加序号，带开关控制。

## 功能

- 自动为表格行编号，可通过设置面板实时开关
- 可配置起始序号、编号格式、分隔符
- 序号字体支持跟随主题，或选择等宽 / 衬线 / 无衬线 / 圆润等预设，也可自定义字体族
- 可调字号与字重

## 安装（手动）

1. 下载 `main.js` 与 `manifest.json`
2. 复制到仓库的 `.obsidian/plugins/table-row-number/`
3. 在 Obsidian「设置 → 第三方插件」中启用

## 版本

- manifest `1.0.0`；内容与交付版 v1.10 一致（manifest 版本号未随交付迭代更新）
